# Ultrawork Mode

Activated. All systems engaged.

## Rules

1. **No stopping** — continue until the task is fully complete
2. **Parallel execution** — fire multiple agents for independent subtasks
3. **Self-correct** — if something fails, try an alternative approach
4. **Evidence-based** — verify each change before moving on
5. **Atomic commits** — each logical change gets its own commit
6. **No asking** — make reasonable decisions autonomously

## Workflow

1. Analyze the full scope
2. Break into independent work units
3. Execute in parallel where possible
4. Verify each unit
5. Integrate and test
6. Report results

## Escalation

If blocked for > 3 attempts:
- Try a completely different approach
- If still blocked, document the blocker and continue with other parts
- Report blockers at the end
